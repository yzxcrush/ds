# Ds Flow 写法（0.2-flow，结构性精简档）

> 状态：**写法档（surface profile）**，语义与 Ds v0.1 完全一致：77 个关键字、类型系统、
> 内存/错误/并发/裸机/元编程能力全部不变，只是换了一套**更短、且与其他编译语言不同的结构**。
> 参考驱动自动识别，可与经典/精简写法共存于不同文件。
>
> 实测：同一批程序 经典 137 token → Flow **69 token（-49%）**；相比 0.1c 再省 **15%**。

## 1. 为什么不是「换皮」

Flow 不复制 C/Java/Python/Rust/Go 的任一结构，而是三条独立语法决策的组合：

1. **函数定义用前缀符 `\`，参数靠空白分隔，不用括号/逗号**：`\add a b = a+b`
2. **调用靠并置（application by juxtaposition），不写括号与逗号**：`p "hi"`、`fib(10)` 仅是复杂实参时的显式形式
3. **多语句块用 `.` 结束，不用花括号**；单语句体用 `:`；条件用 `?`，`else` 可缩写为 `;`，返回用 `^`

没有 `fn main`、没有 `package`、没有 `{}`、没有 `;` 语句分隔、没有逗号参数列表。
范式上接近「函数应用 + 结束符」，与任何主流编译语言都不是同一种骨架。

## 2. 识别与兼容

满足任一条件即按 Flow 解析：

- 文件名以 `.dsf` 结尾；
- 文件以 `\` 开头（函数定义）；
- 第一行是 `#!flow`。

普通 `.ds` 文件行为完全不变。Flow 文件里**仍可**使用 `{...}`（例如需要 `class`/`match` 等高级结构时），两种写法可混用。

## 3. 规则

### F1 隐式入口

顶层语句即入口；声明先注册，再按顺序执行顶层语句。没有 `package` / `fn main`。

```dsf
p "hello, Ds"
```

### F2 函数定义 `\`

```
\名字 参数1 参数2 ... [-> 返回类型] (= 表达式 | : 单语句 | 块)
```

- 参数空白分隔，可写 `a` 或 `a:i32`；不需要括号和逗号。
- `= 表达式` 是最短形式；`:` 后单条语句；否则进入 `.` 结束的多语句块。

```dsf
\add a b = a+b
\fib n = ?n<2: n; fib(n-1)+fib(n-2)

\main
    p "multi-line body"
    p "ends with dot"
.
```

### F3 并置调用

在表达式位置，函数名后跟原子实参即调用；**同一层收集多个原子作为实参**：

```dsf
p "hi"          # println("hi")
p x             # println(x)
add 2 3         # add(2, 3)
p add(2,3)      # println(add(2,3))：嵌套应用请加括号
```

规则：原子 = 标识符 / 字面量 / 字符串 / 数组 / `(...)`；嵌套调用用括号分组。
显式 `f(a,b)` 仍然合法，两种写法可混用。

### F4 `.` 结束块

多语句体以单独一个 `.` 结束（可嵌套，内层 `.` 先结束）：

```dsf
for i in 1..6
    total+=i
.
```

单语句体可用 `:` 内联，无需 `.`：

```dsf
for i in 1..6: total+=i
```

### F5 条件与返回

`?` 是 `if`；`^` 是 `return`；`else` 可写成 `;`（内联时最省）：

```dsf
\sign n
    ?n<0
        ^ -1
    else
        ?n>0
            ^ 1
        .
        ^ 0
    .
.

\sign n = ?n<0: -1; ?n>0: 1; 0
```

### F6 循环

`while` / `for` / `loop` 关键字不变，块体用 F4 的 `.` 或 `:` 形式：

```dsf
var n=0
while n<3
    n+=1
.
for i in 0..3: p i
loop
    n-=1
    ?n<=0: !
.
```

### F7 能力不变

`class`/`trait`/`impl`/`match`/`opt`/`res`/`try`/`catch`/`spawn`/`chan`/`alloc`/`comptime`/`macro` 等
语义全部保留；在 Flow 文件中这些高级结构可继续用 `{...}` 写法（混用合法，见 §5）。

### F8 短别名

prelude 提供 1 字符别名：`p`=println、`s`=str、`l`=len、`r`=range。
（可被同名绑定遮蔽；经典文件也可用。）

### F9 其余沿用 0.1c

范围 `a..b`、f-string `f"{x}"`、复合赋值 `+= -= *= /= %=`、首次赋值隐式不可变、类型可省、`;` 可选。

## 5. 示例（可运行）

```
# examples/flow/fib.dsf
\fib n = ?n<2: n; fib(n-1)+fib(n-2)
for i in 0..10: p f"fib({i})={fib(i)}"
```

```
# examples/flow/sum.dsf
var total=0
for i in 1..6: total+=i
p f"total={total}"

\add a b = a+b
p add(2,3)
p ?total>10: "big"; "small"
```

Flow 文件里混用经典结构（高级能力）：

```
\show x
    match x { 0 => p "zero", _ => p "other" }
.
show 0
```

## 7. 已知限制

- 并置调用按「最外层收集原子实参」；嵌套应用需加括号（`p fib(10)`）。
- `\` 定义用于顶层函数；`class`/`impl` 内方法暂用经典 `fn name(...)` 形式。
- 参数用空白分隔，因此参数不能是复杂模式（本版本仅标识符，可选 `:type`）。
- 负数实参请加括号：`f(-1)`（`f -1` 会被视为 `f` 减去 1）。
