# Ds 0.1c 精简写法（Token-minimal Profile）

> 状态：**写法档（surface profile）**，叠加在 Ds v0.1 之上。
> **语义、77 个关键字、类型与运行时行为完全不变**；只是让「写」更短，对 AI 更省 token。
> 参考驱动同时接受「经典写法」与「精简写法」，两者可混用。
> 实测：常见程序平均省 **31%** token（hello world 省 61%，错误处理省 45%）。

## 1. 设计目标

1. **最少样板**：没有 `package`、没有 `fn main` 外壳。
2. **最少符号**：`let` 可省、类型标注可省、单语句块可省花括号、`+ 1` 可写 `+= 1`。
3. **AI 友好**：所有简化都是机械、可预测的语法糖，模型不需要记新语义。
4. **完全兼容**：旧写法仍合法；两种风格可混用。

## 2. 规则

### C1 隐式入口（无 `package` / 无 `fn main`）

顶层语句即入口；声明（`fn`/`type`/`class`/`impl` 等）先注册，再按顺序执行顶层语句。
若**没有**顶层语句且存在 `fn main`，则自动调用 `main`（经典行为）。

```ds
println("hello, Ds")          # 1 行程序
```

```ds
fn add(a,b)=a+b               # 声明
println(add(2,3))             # 顶层语句 = 入口
```

### C2 表达式函数体：`=` 或 `:`

```ds
fn add(a,b)=a+b               # 等价于 { a + b }
fn say(x): println(x)         # 单语句体
```

原写法仍可用：

```ds
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

### C3 单语句块：`:` 或直接跟随

`if` / `while` / `for` / `loop` 的单条语句体可以去掉花括号：

```ds
for i in 0..10: println(i)    # 等价 { println(i) }
if x>0: println("+")
else: println("-")

while n<3: n+=1
```

### C4 变量：可省 `let`

首次赋值即定义**不可变**绑定；需要可变时用 `var`：

```ds
x = 1                         # 等价 let x = 1（不可变）
var n = 0                     # 可变
n += 1
```

对已定义名字赋值仍是普通赋值；对不可变名字赋值会报错。

### C5 复合赋值

`+=` `-=` `*=` `/=` `%=` `&=` `|=` `^=` `<<=` `>>=`，作用于变量/数组下标/映射键。

```ds
var total=0
for i in 1..6: total+=i
xs[0]+=10
m["n"]+=1
```

### C6 范围 `a..b`（半开区间）

`a..b` 等价 `range(a, b)`，返回可迭代数组：

```ds
for i in 0..10: println(i)
let xs = 0..3                 # [0 1 2]
```

### C7 插值字符串 `f"..."`

`f"..."` 中 `{表达式}` 求值后拼接；`{{`/`}}` 表示字面花括号；其余转义规则同普通字符串。

```ds
let x=42
println(f"x={x} next={x+1} {{ok}}")
```

### C8 类型标注全部可省

参数、返回值、变量都可省略；需要精确 ABI/布局时再写。

```ds
fn add(a,b)=a+b
```

### C9 `..` 与 `range` 并存

`0..3` 与 `range(0,3)` 等价；经典写法不受影响。

### C10 可选 `;`、可选空行

语句以换行或 `;` 结束；两者等价。

## 3. 前后对比（同一程序）

```ds
# 经典
package hello
fn main() {
    println("hello, Ds")
}
```

```ds
# 精简
println("hello, Ds")
```

| 场景 | 经典 token | 精简 token | 节省 |
|---|---|---|---|
| hello world | 13 | 5 | 61% |
| 斐波那契 10 项 | 64 | 38 | 40% |
| 值类型 + 方法 | 75 | 64 | 14% |
| 类 + 继承 | 66 | 56 | 15% |
| 错误处理 + f-string | 85 | 46 | 45% |
| **常见程序合计** | **303** | **209** | **31%** |

> token 计数以参考词法器的有效 token 计（`python3 tools/token_report.py` 可复跑）。

## 5. 建议用法

- **AI 生成/训练默认用精简写法**（省 token、结构更平）；
- 需要 ABI、裸机、对外 API、可读性优先时用经典写法；
- 两者可以混用，格式化/生成器无需强制统一。

## 6. 新增 token

`..`、`+=` `-=` `*=` `/=` `%=` `&=` `|=` `^=` `<<=` `>>=`、`f"..."` 插值字符串。
关键字表仍是 **77 项**，未新增关键字。
