# Batch 4 — 内存 / 指针 / AddrSymbol / Cut 边界 + 语法歧义

## 语法歧义检查（全部可判）

| 歧义点 | 判定规则 | 状态 |
|---|---|---|
| `a * b` vs `*p` | 表达式起始/运算符后为解引用；操作数后为乘法 | ✅ |
| `a & b` vs `&x` | 同上；`&` 前缀=地址，中缀=按位与 | ✅ |
| `1..3` vs `1.` | `..` 区间优先；浮点 `1.` 不允许（必须 `1.0`） | ✅ |
| `1...3` | 无 spread 语法，明确报错 | ✅ |
| `@irq` / `@asm` / `@static` | `@` 后只接属性名或 `{`；层内属性单独解析 | ✅ |
| `x: p()` 标签 vs `x: T` 类型 | 语句起始 IDENT+`:` 为标签；声明位置为类型注解 | ✅ |
| `{...}` 块 vs 映射 | `{k:v}` / `{:}` 映射；其他为块 | ✅ |
| `[` 数组 vs 索引 vs 类型 | 表达式位置：开头数组、后缀索引；类型位置数组/泛型 | ✅ |
| `<` 比较 vs 泛型 | Ds 泛型用 `[]`，`<` 永远是比较 | ✅ |
| `|>` vs `|` | 最长匹配 + 优先级；管道最低 | ✅ |
| `->` vs `- >` | 最长匹配；箭头是单独记号 | ✅ |
| `*T` 指针类型 | **原来 base parser 不接受**；Cut 需要它 | ✅ 已加入 `PtrType` |

## Batch 4 已修

- Python `parse_type` 支持 Cut 的 `*T`（映射为 `PtrType`）。
- Python `@static NAME: T = ADDR` 运行期改为 `Ptr(addr=...)`，`*NAME` 不再报“不能解引用 int”。
- C/Python 的 `@static` 形式都能通过 `--check`。

## 未解决（B3，仍然阻塞）

| 问题 | 现状 |
|---|---|
| Cut `@static` 是地址符号，Ds `static` 是存储 | base 用 `Ptr` 模拟，C 运行期仍不支持指针 |
| `p(UART)` 跨端表示 | Python 打印 `<ptr...>`，C 打印 `4096` |
| C 驱动指针/解引用 | C 明确报“不支持指针”，不是静默错编 |
| `@static` 写 MMIO | base 只读 0；Cut 才应生成真实地址访问 |
| 指针算术 | base `ptr+1` 目前报类型错误；Cut 禁止；需在 AddrSymbol 中统一定义 |

- **内存语义：部分冻结**；B3 未解决，不能冻结整个 Batch 4。
