Why Ds

One language, three deliverables

Write apps (--app), systems code and bare-metal firmware (--bare) with the same types, errors, memory and concurrency rules. 7 targets incl. thumbv7em-none-eabi, riscv32-none-elf, wasm32.

Capability density

Types, five explicit memory strategies, layered errors, 8 concurrency primitives, 4-stage metaprogramming, OOP + traits, pattern matching and bare-metal placement — all first-class keywords, not library layers.

Token efficiency

Classic 137 → concise 82 (−31%) → Flow 69 (−49%) tokens on common programs. Same AST, byte-identical behaviour. Flow uses \ definitions, juxtaposition calls and . block terminators.

Predictability

Static types, no implicit conversions, deterministic drop, error layering (res/opt → panic → assert), structured concurrency, layout control (sizeof/alignof/packed), explicit @unsafe.

AI-native, not prompt-only

llms.txt, a 5k-token language card, 41 SFT rows, 25 benchmark tasks, an auto-grader and three implementations cross-checked by differential tests. Generated code can be executed and scored immediately.

Not a re-skin

Flow's combination of \ sigils, whitespace application and dot-terminated blocks belongs to no mainstream compiled-language syntax family. Three surfaces, one semantics.

Three syntaxes, one AST

Status & scope

v0.1 is definition-first. It ships a full spec, three reference implementations (Python, C core subset, Android kernel), differential tests and an AI learning kit. There is no package manager, standard library ecosystem or production tooling yet. Great for language design/teaching, prototyping, and AI-generation pipelines — not a production replacement for Python/Rust/Go/C++.
