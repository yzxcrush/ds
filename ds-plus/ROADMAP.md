# Ds+ 路线图（P0–P6）

| 阶段 | 内容 | 状态 |
|---|---|---|
| P0 | 双分支结构契约、关键字冻结、ds-core 共享 | ✅ 完成 |
| P1 | 前端：16 个 `@` 令牌、base AST 等价、三档写法一致 | ✅ 完成（S14/S15） |
| P2 | 语义：checker（profile/unsafe/常量/对齐）+ compat 模拟执行 + `@asm` 输入操作数 | ✅ 完成（S16） |
| P3 | IR 规范化 + ABI 指纹 + 超集稳定 | ✅ 完成（S17） |
| P4 | x86-64 子集代码生成：ELF / raw binary（`--raw`） | ✅ 完成（S18，子集） |
| P5 | CLI（check/run/ir/abi/build）+ Ds+ SFT/语言卡 | ✅ 完成 |
| P6 | v0.1.0 预览发布：版本号、发布说明、打包 | ✅ 本分支发布物 |

## 明确未完成（后续版本）

- P4 后端：字符串/GC/异常/并发/类/宏、`@mmio` 代码生成、优化、链接脚本、非 x86-64 后端。
- P2：完整类型推断/借用检查；`@asm` 输出/clobber 约束；中断/页表仿真。
- P5：Ds+ 评测集/自动评分器、llms 分支入口、Android 内核适配。
- P6：稳定版（v0.2+）与生态。
